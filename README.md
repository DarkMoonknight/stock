# EzyProcure — Procurement ERP

A construction procurement management system for multi-site operations.

## MVP
- Dashboard
- Projects & sites
- Material master
- Vendor master
- Purchase requisitions
- RFQs
- Quotation comparison
- Purchase orders
- Delivery & GRN
- Invoice/payment tracking
- Procurement reports
- AI procurement assistant

## Workflow
Requirement → PR → RFQ → Quotations → Comparison → Approval → PO → Delivery → GRN → Invoice → Payment

## Security
Keep API keys and database credentials in environment variables/secrets. Never commit secrets to this repository.

## Status
MVP architecture initialized. Production modules will be added incrementally.
